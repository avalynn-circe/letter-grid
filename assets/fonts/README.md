# Vendored fonts

These are **subsets** of the upstream Google Fonts, generated by
`tools/build-fonts.sh` and checked in deliberately.

## Why

The `@expo-google-fonts` packages ship each family complete. Baloo 2 alone is
410 KB across 1,585 glyphs because it carries a full Devanagari set; Libre
Franklin and JetBrains Mono carry Cyrillic and Greek. Nothing in this app can
render any of it, and every byte shipped is a byte downloaded by someone who
will never see it.

## What changed, and what did not

Subsetting **removes glyphs**. It does not touch the ones that remain — the
outlines, advance widths and em size of every character this app draws were
verified byte-identical to the originals. Nothing changes on screen.

Emoji were never in these fonts and still are not; they render from the system
emoji font exactly as before.

The subset range was chosen by scanning every source file and content file in
the line for the characters actually used, then widening to whole Unicode blocks
so a new symbol added later is unlikely to fall outside it:

    U+0020-007E,U+00A0-00FF,U+200B-200F,U+2010-2027,U+2030-205E,U+2070-209F,U+20A0-20BF,U+2100-214F,U+2190-21FF,U+2200-22FF,U+2300-23FF,U+25A0-25FF,U+2600-27BF

## Licence

All three families are the SIL Open Font License 1.1 with **no Reserved Font
Name** — the copyright lines read "Copyright YYYY The X Project Authors" with no
"with Reserved Font Name" clause. The OFL permits modification and
redistribution, and with no RFN the subsets keep their original names. Each
upstream `LICENSE_FONT` is included here, as the OFL requires.

## Regenerating

    pip install fonttools
    npm install            # @expo-google-fonts packages are devDependencies
    ./tools/build-fonts.sh
